# T-17 · Supabase repository + Auth + Invites

## Mục tiêu
Bật backend thật: khi có env Supabase, app dùng Postgres/Auth/RLS thay cho Local, có
đăng nhập, nhận **mã mời** để tham gia dòng họ, và tôn trọng vai trò Owner/Editor/Member.

## Ngữ cảnh cần biết
- PRD §5.2: private + mã mời + vai trò + RLS. Schema/RLS/RPC đã có ở T-16.
- `getRepository()` (T-08) trả Supabase khi có `NEXT_PUBLIC_SUPABASE_URL` — task này hiện
  thực nhánh đó, **cùng interface `DataRepository`** để UI không đổi.

## Phạm vi
**Trong:** `client.ts` (khởi tạo supabase-js từ env), `supabaseRepository.ts` (hiện thực
đầy đủ interface + `snapshot` bằng vài truy vấn theo `clan_id`), `mappers.ts` (row↔domain),
`dang-nhap` (email/OTP/Google), `join/[code]` (gọi RPC `redeem_invite`), `AuthGate` (chặn
khi chưa đăng nhập lúc backend bật).

**Ngoài:** đổi schema (T-16). Khi **không** có env, mọi thứ vẫn chạy Local (không hồi quy).

## Đầu vào đã có
- `T-08`: interface `DataRepository`, `getRepository()`. `T-16`: bảng/RLS/RPC. `@supabase/supabase-js`.

## Việc phải làm
1. `client.ts`: tạo client từ `NEXT_PUBLIC_SUPABASE_URL`/`ANON_KEY`; chỉ nạp khi có env.
2. `mappers.ts`: chuyển snake_case row ↔ domain types (gồm `jsonb` DualDate).
3. `supabaseRepository.ts`: CRUD + `snapshot(clanId)` (truy vấn members/parent_links/
   unions/branches theo clan); `memberships.myRole`; `invites.redeem` gọi RPC.
4. `dang-nhap`: đăng nhập Email magic-link/OTP + Google (tùy cấu hình dự án).
5. `join/[code]`: đăng nhập nếu cần → gọi `redeem_invite` → vào dòng họ.
6. `AuthGate`: khi backend bật mà chưa đăng nhập → điều hướng `dang-nhap`.

## Quy ước bắt buộc
- Giữ **đúng interface** với Local (CONVENTIONS §2) để UI không phân biệt backend.
- Không commit khóa; chỉ `.env.example` (CONVENTIONS §8).
