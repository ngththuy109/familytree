# T-01 · Khởi tạo dự án Next.js + TS + Tailwind + PWA + hạ tầng test

## Mục tiêu
Có bộ khung dự án chạy được (`npm run dev`) để mọi task sau cắm vào: Next.js App
Router + TypeScript + Tailwind, PWA cài đặt được, và hạ tầng kiểm thử
(typecheck/vitest/playwright) với các script chuẩn.

## Ngữ cảnh cần biết
- Stack đã chốt (PRD §5.1): Next.js App Router + TS + **PWA**, **static-export**
  (`output: 'export'`) để host $0. App **chủ yếu client-side** vì dữ liệu local-first.
- Mobile-first (PRD §4); cần biến CSS `--font-scale` + thuộc tính `[data-elderly]`
  trên `<html>` cho chế độ người lớn tuổi (T-09 dùng lại).
- Tên hiển thị app: "Gia Phả Việt".

## Phạm vi
**Trong:** cấu hình dự án; layout gốc + `globals.css`; thanh điều hướng dưới
(BottomNav) + TopBar rỗng; trang chủ tạm; manifest + icon PWA; service worker cơ
bản (offline app-shell); cấu hình Vitest + Playwright + ESLint; script chuẩn.

**Ngoài:** không viết business logic, không tạo dữ liệu, không dựng màn hình tính
năng (để các task sau). Không cấu hình Supabase ở đây.

## Đầu vào đã có
- Repo trống. `docs/tasks/CONVENTIONS.md` (mục 1, 2, 6) quy định TS strict, ranh
  giới thư mục, tên script.
- Chưa có gì để dùng lại.

## Việc phải làm
1. `package.json` với deps: `next`, `react`, `react-dom`, `tailwindcss`,
   `postcss`, `autoprefixer`; devDeps: `typescript`, `@types/*`, `vitest`,
   `@testing-library/react`, `jsdom`, `@playwright/test`, `eslint`,
   `eslint-config-next`, `prettier`. Scripts đúng CONVENTIONS §6.
2. `next.config.mjs`: `output: 'export'`, `images.unoptimized: true`. Đăng ký PWA
   (service worker tự viết trong `public/` hoặc dùng cách nhẹ; không thêm lib nặng).
3. `tsconfig.json`: strict, path alias `@/*` → gốc dự án.
4. Tailwind: `tailwind.config.ts` quét `app/**`, `components/**`; khai báo biến
   `--font-scale`; biến thể `data-elderly`.
5. `app/layout.tsx`: `<html lang="vi">`, khung providers (rỗng, để T-09 gắn store),
   BottomNav (Trang chủ / Cây / Danh sách / Giỗ / Tìm kiếm) + TopBar.
6. `app/globals.css`: reset, token màu (light + dark), cỡ chữ theo `--font-scale`,
   khối `[data-elderly="true"]` tăng `--font-scale` ~1.3 + tương phản cao.
7. `app/page.tsx`: trang chủ tạm (tên app + link demo).
8. `public/manifest.webmanifest` + icon 192/512/maskable (SVG/PNG đơn giản); khai
   báo manifest trong `layout`. Service worker cache app-shell.
9. Vitest (`jsdom`) + Playwright (`e2e/`, dùng Chromium `/opt/pw-browsers`) chạy được.

## Quy ước bắt buộc
- TS strict, không `any` ngầm (CONVENTIONS §1). Server Component mặc định, `'use client'`
  khi cần (§1). Tên script đúng §6. Chỉ sửa file trong `touches` (§2).

## Định nghĩa "xong"
Chạy `npm run dev` mở được app với điều hướng dưới; `build`, `typecheck`, `test`,
`e2e` đều xanh.

## Cạm bẫy đã biết
- `output: 'export'` không cho dùng API route/SSR động → giữ mọi thứ client/static.
- Playwright trong môi trường này: KHÔNG chạy `playwright install`; trỏ Chromium sẵn
  ở `/opt/pw-browsers`.
- Đừng thêm thư viện PWA nặng; service worker viết tay là đủ.

## Đã làm gì
- Dựng Next.js 14 (App Router) + TS strict + Tailwind (token màu qua CSS var, `--font-scale`,
  `[data-elderly]`); `next.config.mjs` bật `output: 'export'` để host tĩnh $0.
- Layout gốc (`app/layout.tsx`) + `TopBar` + `BottomNav` (5 mục) + `RegisterSW`; trang chủ
  (`app/page.tsx`) với các ô điều hướng.
- PWA: `manifest.webmanifest` + icon SVG (thường/maskable) + `public/sw.js` (cache app-shell,
  network-first cross-origin).
- Hạ tầng test: Vitest (jsdom) + Playwright; script `dev/build/typecheck/test/e2e/lint`.
- **Kết quả:** `typecheck` ✓, `test` ✓ (2/2 smoke), `build` (static export, 4 trang) ✓.
- **Điều chỉnh:** dùng route cấp cao tiếng Việt (`/cay`, `/danh-sach`, …) + clan hiện tại
  trong store thay cho `[clanId]` trên URL, vì static export không prerender được id sinh ở
  runtime (IndexedDB). Chi tiết id đi qua query param ở các task sau.
