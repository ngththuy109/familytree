# T-18 · Hoàn thiện PWA + Tài liệu triển khai

## Mục tiêu
Đưa app thành PWA cài đặt được, chạy offline app-shell, và hoàn tất bộ tài liệu phản
ánh **đúng** hệ thống đã dựng (mô hình dữ liệu, bảo mật, cài đặt/triển khai, lộ trình).

## Ngữ cảnh cần biết
- PRD §4 (mobile PWA), §5 (kiến trúc/bảo mật), §6 (roadmap). Viết **sau** khi schema
  (T-16) và app ổn định để tài liệu khớp thực tế.
- Đã có `docs/PRD.md`, `docs/KIEN_TRUC.md`, `docs/tasks/*` (T-03).

## Phạm vi
**Trong:** service worker (precache app-shell + fallback offline; network-first cho dữ
liệu Supabase), manifest hoàn chỉnh + icon maskable, và 4 tài liệu: `MO_HINH_DU_LIEU.md`
(ERD + bảng + index), `BAO_MAT.md` (vai trò, RLS, mã mời/RPC, HTTPS, export/backup),
`CAI_DAT_TRIEN_KHAI.md` (chạy local, cấu hình Supabase, deploy Vercel/Cloudflare),
`LO_TRINH.md` (đã làm gì / Giai đoạn 2).

**Ngoài:** không sửa logic tính năng; không đổi schema.

## Đầu vào đã có
- `T-01` khung PWA; `T-16` schema/RLS để mô tả chính xác; toàn bộ code các task.

## Việc phải làm
1. `sw.js`: precache route/asset tĩnh; chiến lược cache-first cho shell, network-first
   cho API; trang offline.
2. `manifest`: name/short_name/theme/background/icons (192/512/maskable), `display: standalone`.
3. `MO_HINH_DU_LIEU.md`: sơ đồ thực thể (Member/ParentLink/Union/Branch/Clan/Membership/
   Invite), bảng Postgres, index, ghi chú "đời computed / nội-ngoại không lưu".
4. `BAO_MAT.md`: mô hình vai trò, chính sách RLS thực tế (trích từ migration), luồng mã
   mời qua RPC, HTTPS/TLS, xuất JSON backup.
5. `CAI_DAT_TRIEN_KHAI.md`: chạy local (local-first, không cần env), bật Supabase (tạo
   project, áp migration, đặt `.env`), deploy static (Vercel/Cloudflare Pages).
6. `LO_TRINH.md`: trạng thái MVP + hạng mục Giai đoạn 2 (PDF/Excel, thông gia, push/email).

## Quy ước bắt buộc
- Tài liệu tiếng Việt (PRD §4). Không tô hồng: ghi đúng phần đã/chưa làm.
