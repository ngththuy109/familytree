# T-15 · Xuất/Nhập JSON (backup)

## Mục tiêu
Cho Admin **xuất toàn bộ dòng họ ra JSON** để tự sao lưu (tránh phụ thuộc nền tảng),
và **nhập lại** từ file JSON.

## Ngữ cảnh cần biết
- PRD §5.2: "Xuất dữ liệu… ra file JSON… bất kỳ lúc nào để tự sao lưu cá nhân".
- Định dạng xuất = `ClanSnapshot` + phiên bản schema để nhập lại an toàn.

## Phạm vi
**Trong:** `toJson(snapshot)` (chuỗi JSON có `version`, `exportedContext`), `fromJson(text)`
(validate + trả snapshot), trang `export` (nút Tải JSON + ô nhập/dán để khôi phục).

**Ngoài:** PDF/Excel (Giai đoạn 2, PRD §6.2). Không đụng schema Supabase.

## Đầu vào đã có
- `T-08`: `snapshot(clanId)` và các hàm ghi để nhập lại.

## Việc phải làm
1. `toJson`: gói `{version, clan, members, parentLinks, unions, branches}`; tải file
   bằng Blob + link tải phía client.
2. `fromJson`: parse + kiểm phiên bản + kiểm toàn vẹn (id tham chiếu tồn tại); trả lỗi rõ.
3. Trang `export`: nút "Xuất JSON" (đặt tên file theo tên họ + ngày); vùng "Nhập JSON"
   (cảnh báo ghi đè), gọi repository ghi lại.

## Quy ước bắt buộc
- `'use client'`. Ghi/đọc qua `getRepository()` (CONVENTIONS §2). Không mất dữ liệu im lặng.
